## A. Canaux v1

### Steam (canal principal)

- **Pourquoi** : audience où vivent les fans de FM, OOTP, Motorsport Manager
- **Cut** : 30% (jusqu'à 1M$ de revenus, puis 25%, 20% au-delà)
- **Avantages** :
  - Discoverability via tags, recommandations
  - Fonctionnalités intégrées : Cloud Save, Workshop (mods communautaires), succès, reviews, Friends activity
  - Trust factor pour les acheteurs
  - Wishlist (signal d'intention d'achat → impact algorithme)
- **Inconvénients** :
  - 100$ Steam Direct fee (refundé après 1000$ de ventes)
  - Dépendance totale à la plateforme
  - Reviews bombing toujours possible

### Itch.io (canal secondaire)

- **Pourquoi** : filet de sécurité, communauté indé, pas de cut
- **Cut** : 0% par défaut (le dev choisit 0-15%)
- **Avantages** :
  - Autonomie totale (pricing, builds, deals)
  - Bêta payante possible avant Steam
  - Communauté plus tolérante aux versions WIP
- **Inconvénients** :
  - Audience plus petite, plus indé/pixel art (moins manager)
  - Moins de discoverability

### Pas inclus en v1
- **GOG** : sélectif (curated), faut postuler. Charge ×3.
- **Direct download** : marketing 100% à charge.
- **App Store / Mac AppStore** : pas la cible, complexité distribution Apple.

### Comparables marché

- New Star Manager : 15€

### Hypothèse v1

- **Bêta privée** : gratuit (testeurs invités)

- **Soldes** : alignés sur les périodes Steam (Halloween, Hiver, Printemps, Été)

## C. Stratégie de mises à jour

### Patchs mineurs (v1.0.x)
- Bugs critiques, équilibrage, calibrage moteur
- Cadence : tous les 1-2 mois post-release

### Patchs majeurs (v1.1, v1.2)
- Nouvelles fonctionnalités demandées par communauté
- Cadence : tous les 4-6 mois

### DLC ?
- **Pas de DLC payant en v1.x** — modèle premium pur (cohérent pilier 5)
- Les ajouts (nouveaux clubs, modes) viennent dans des updates gratuits

### V2.0 (online) — vente comme upgrade payant
- Possibilité : V2.0 vendu comme expansion (10-15€) plutôt que update gratuit
- Justifie le coût ops récurrent du backend
